# Persona avatars — provenance

VOICE-AGENT-118. One illustrated portrait per persona, displayed in the app while the agent
speaks. The rendered files live in `app/static/souls/<slug>.webp` (512x512, WebP q82,
downscaled from 1254x1254 PNG masters); this file records **how they were made**, so the set
can be extended or restyled without guessing.

(The leading underscore matters: `_read_agent_souls()` globs `souls/*.md` and treats every
match as a selectable persona. Files whose stem starts with `_` fail the slug pattern and are
skipped, which is how `_core.md` and this file stay out of the persona list.)

**One character = one file.** The persona's prose, its `voice:` and its avatar subject
description all live in `souls/<slug>.md` (the description sits inside the file's HTML comment,
which the loader strips, so it can never reach the model). This file only holds what is shared
by the whole set: the style lock and the run notes.

## Why the composition is what it is

The avatar is displayed small (a circle of roughly 56 px). At that size a face is unreadable,
so identity is carried by three signals only, and each persona must differ on all three:

| persona | silhouette | dominant colour | held object |
|---|---|---|---|
| `default` | seated, compact, hand under the chin | deep green (the app accent, `#0f6b5f`) | none |
| `video-store` | leaning forward, forearm low across | amber plaid over brick red | VHS cassette |
| `scholar` | upright, hand raised in a pinch near the face | indigo over cool grey | 35 mm film loop |
| `chatterbox` | leaning forward, one hand open and wide | bright orange | mug held aloft |

The masters are square because the badge is a circle. Corners are empty paper by design
(`Composition safe for a circular crop`), so the circular mask costs nothing. They are **not**
cropped tighter on the face: at badge size the object and the colour identify the character
better than the features do.

## Style lock (`PERSONA_STYLE_VERSION = 1`)

Same discipline as the `synthetic-images` repo: **style words live only in this block**, and the
per-persona text is a pure subject description. Paste this block verbatim, then append the one
description from the persona's own file.

```
Illustrated character plate in the style of a 1990s printed visual dictionary.
Single human figure, bust framing, three-quarter view, centred, head in the
upper half with generous even margin around it, shoulders reaching the bottom
edge. Composition safe for a circular crop: nothing meaningful in the corners.
Flat lighting, plain off-white textured paper background, encyclopedic
technical-illustration style, soft realistic shading, educational reference
aesthetic, minimalist composition.
Invented character, not resembling any real or recognizable person. No film
posters, no logos, no brand marks, no packaging.
Just the illustrated figure on the paper, nothing else: no text, no title, no
caption, no labels, no callouts, no annotations, no leader lines, no arrows, no
legend, no numbers, no letters, no measurement marks, no border.
Aspect ratio 1:1.
{character_description}
```
